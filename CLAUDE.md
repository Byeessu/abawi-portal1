# CLAUDE.md

## 🏗️ Standards de Développement

- **Architecture :** Design patterns propres (SOLID, Clean Architecture).
- **Performance :** Optimise la complexité algorithmique (Big O).
- **Code Style :** Code auto-documenté, typage strict, immuabilité par défaut.
- **Documentation :** Chaque nouvelle fonctionnalité doit être accompagnée de ses tests unitaires.

## 🎯 Règles de Sortie "Excellence"

- **Concision :** Réponses denses, techniques et sans remplissage poli inutile.
- **Visuel :** Utilise les Artifacts pour tout nouveau composant ou structure de données.
- **Langue :** Code et logs en Anglais, explications techniques en Français.

## 🛑 Sécurités Critiques

- Ne jamais supprimer de données sans sauvegarde.
- Vérifier l'impact sur les dépendances existantes avant toute installation.
- Valider chaque correctif avec le script de test correspondant.
